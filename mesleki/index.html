Tanıtım — Course Introduction (Hafta 1)

Ders Amacı ve Kapsam

Mesleki İngilizce dersi, bilgisayar programcılığı öğrencilerinin iş hayatında, stajda ve uluslararası kaynaklarda ihtiyaç duyacağı temel İngilizceyi A2 seviyesinde öğretir. Ders yalnızca gramer değil; listening, speaking, reading, writing dört becerisini dengeli geliştirir.

Üç ana bağlam vurgulanır:

  • Work English (iş): ofis, takım çalışması, toplantı, e-posta
  • Home English (ev): günlük iletişim, teknoloji kullanımı
  • Education English (eğitim): ders, sınav, Oxford kitabı aktiviteleri
Course objectives (English):
- Use basic English in IT workplaces
- Understand simple technical texts and instructions
- Participate in pair work and short presentations
- Build vocabulary for hardware, software, and the web
İpucuKitaptaki her ünite sonunda review bölümü vardır; vize öncesi bu özetleri mutlaka çözün.

Oxford EAP Elementary (A2)

EAP (English for Academic Purposes) = akademik amaçlı İngilizce. Elementary A2, Avrupa Ortak Dil Referans Çerçevesi’nde temel-altı seviyedir: basit cümleler, sık kullanılan kelimeler, tanıdık konularda kısa metinler.

IT Sektöründe Çalışmak (Hafta 2)

Working in IT

IT (Information Technology) = bilgi teknolojileri sektörü. Yazılım, donanım, ağ, destek ve veri alanlarını kapsar. Türkiye’de ve abroad (yurt dışında) IT iş ilanları İngilizce yayınlanır; temel terimleri bilmek başvuruda avantaj sağlar.

The IT sector is growing fast.
Many companies need programmers and technicians.
I work in the IT department.
We solve technical problems for users.
Sınavda sorulabilirIT = Information Technology. department = departman.

Pair Work (Çift Çalışma)

Derste pair work = iki öğrenci birlikte alıştırma yapar. Amaç konuşma pratiği ve geri bildirimdir.

Teacher: "Work in pairs. Student A asks, Student B answers."
Student A: "What do you do in IT?"
Student B: "I write code and test applications."
Student A: "Do you like your job?"
Student B: "Yes, it's interesting but sometimes stressful."
  1. Partnerinize soru sorun, not alın.
  2. Rol değiştirin (swap roles).
  3. Sınıfa kısa özet verin (report back).

Donanım — Computer Hardware (Hafta 6)

Computer Systems

Computer system = donanım + yazılım + kullanıcı + veri. Girdi → işleme → çıktı modeli IT dersinde de geçerlidir.

A desktop computer stays on your desk.
A laptop is portable — you can take it to class.
A tablet has a touch screen.
Servers run in data centres and are always on.
  • Input devices: keyboard, mouse, microphone, scanner
  • Output devices: monitor, printer, speakers
  • Processing: CPU on the motherboard
  • Storage: HDD, SSD, USB flash drive

Question:

Working with Computers — Present Continuous (Hafta 8)

Present Continuous: am / is / are + -ing

Şimdiki zaman (Present Continuous) şu anda devam eden eylemler için kullanılır. Kalıp: am/is/are + verb-ing.

SubjectFormExample
Iam + -ingI am writing code.
he/she/itis + -ingShe is testing the app.
you/we/theyare + -ingWe are installing updates.

Zaman ifadeleri: now, right now, at the moment, currently

Negative: He is not (isn't) debugging.
Question: Are you using the server right now?
Yes, I am. / No, I'm not.

-ing kuralları: write → writing, run → running (çift sessiz), make → making (sessiz e düşer).

IT Examples — Present Continuous

I am working from home today.
The technician is fixing the network.
They are developing a new mobile app.
The CPU is running at 90% — the computer is slowing down.
Are you downloading a large file right now?
The team is not meeting now; they are coding.

Present Simple vs Continuous:

  • Simple: habits — I write code every day.
  • Continuous: now — I am writing code now.
İpucuState verbs (know, like, belong) genelde continuous almaz: ❌ "I am knowing" → ✓ "I know Python."

Modal Verbs — can, must, have to (Hafta 9)

can — Ability and Permission

can + base verb = yapabilmek (yetenek) veya izin (bağlama göre).

Ability:
I can write Python and C#.
She can configure a router.
We can't fix it without admin rights.

Permission (informal):
Can I use your laptop?
You can leave early today.
FormExample
canI can install Linux.
cannot / can'tHe can't access the server.
Can ...?Can you restart the service?
Sınavda sorulabilircan sonrası fiil yalın halde: can install (✓), can to install (✗).

must / mustn't — Obligation and Prohibition

must = güçlü zorunluluk (sorumluluk). mustn't = kesinlikle yapma (yasak).

Obligation:
You must save your work before shutting down.
Students must attend 70% of classes.

Prohibition:
You mustn't share your password.
You mustn't install unknown software on college PCs.
Dikkatmustn't ≠ don't have to. mustn't = yasak; don't have to = zorunlu değil.

have to / don't have to

have to = dış kurallar, iş gereği zorunluluk. don't have to = zorunlu değil (isteğe bağlı).

have to:
I have to wear an ID badge at the company.
Technicians have to document every repair.

don't have to:
You don't have to come on Saturday — it's optional.
We don't have to use Windows; Linux is OK too.

doesn't have to (he/she/it):
He doesn't have to work night shifts.
ModalMeaningIT example
muststrong obligationYou must back up data.
mustn'tprohibitionYou mustn't delete system files.
have toexternal ruleWe have to use 2FA.
don't have tono obligationYou don't have to buy a GPU for web dev.

IT Modal Examples — Karışık Alıştırma

1. Junior developers can ask seniors for help.
2. You must not click links in suspicious emails. (mustn't)
3. All users have to change passwords every 90 days.
4. You don't have to install every update immediately.
5. Can the server handle 1000 users? — I think it can.

Türkçe özet:
can = -ebilmek
must = mutlaka (iç kural)
have to = zorunda (dış kural)
mustn't = yasak
don't have to = gerek yok
