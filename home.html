JavaScript Temelleri (Ders 1)

JavaScript'in Tarihi ve Web'deki Yeri

1990'ların ortasında web sayfaları çoğunlukla statik HTML'den oluşuyordu; her etkileşim sunucuya gidip geri gelmek zorundaydı. Netscape, tarayıcıda çalışan hafif bir betik dili istedi ve Brendan Eich kısa sürede JavaScript'i geliştirdi. Dil önce LiveScript, sonra pazarlama nedeniyle JavaScript adını aldı; Java ile ilişkisi yoktur — tamamen farklı dillerdir.

ECMA, dili standartlaştırarak ECMAScript (ES) adını verdi. Bugün duyduğumuz ES6, ES2020 gibi sürüm numaraları bu standarttan gelir. JavaScript yorumlanan bir dildir: tarayıcı veya Node.js kodu satır satır çalıştırır. Modern motorlar (V8, SpiderMonkey) sayesinde performans çok yüksektir.

  • Tüm büyük tarayıcılar JavaScript'i yerel destekler.
  • Ön yüzden backend'e (Node.js) kadar tek dilde uçtan uca geliştirme mümkündür.
  • YouTube, Gmail, Netflix gibi siteler JS kapalıyken çoğu özelliği kaybeder.
İpucuTarayıcıda JS'i geçici kapatıp bir haber sitesine girerek reklamların çoğunun JS ile yüklendiğini gözlemleyebilirsiniz — ders notlarındaki "deney" örneğidir.
Sınavda sorulabilirJavaScript'in yorumlanan dil olması, ECMAScript ile ilişkisi ve Java'dan farkı kısa tanım sorularında çıkar.

Uzun betikler için Sources → Snippets kullanın: yeni snippet oluşturup adlandırın, kodu yazın, sağ tık → Run veya Ctrl+Enter ile çalıştırın.

JavaScript Sözdizimi Temelleri

JavaScript'te her ifade genelde noktalı virgülle biter (otomatik noktalı virgül ekleme de vardır). Bloklar süslü parantez { } ile tanımlanır. Yorum satırları: tek satır //, çok satır /* */.

Dil büyük/küçük harfe duyarlıdır: myVar ile myvar farklı değişkenlerdir. String'ler tek veya çift tırnakla yazılabilir; template literal için backtick ` kullanılır.

// Değişken ve sabit
let sayac = 0;
const PI = 3.14;

/* Çok satırlı yorum */
let mesaj = `Merhaba ${sayac}`;
İpucuKonsolda tanımsız değişken kullanırsanız ReferenceError alırsınız — bu, ismin yanlış yazıldığını veya kapsam dışı olduğunu gösterir.

Veri Tipleri: String, Number, Boolean

JavaScript dinamik tipli bir dildir; aynı değişkene farklı tipte değer atanabilir (modern projelerde let/const ile tutarlı kullanım tercih edilir). Temel primitif tipler:

typeof operatörü bir değerin tipini string olarak döndürür:

typeof "abc";      // "string"
typeof 10;         // "number"
typeof true;       // "boolean"
typeof undefined;  // "undefined"
Sınavda sorulabilirtypeof null sonucu tarihsel bir hata nedeniyle "object" döner — bunu ezberleyin.

Değişkenler: var, let, const ve prompt

Eskiden yalnızca var vardı; fonksiyon kapsamına sahiptir ve hoisting davranışı kafa karıştırıcıdır. ES6 ile let (blok kapsamlı, yeniden atanabilir) ve const (blok kapsamlı, yeniden atama yok) geldi. Sınav ve projelerde let/const tercih edin.

prompt() tarayıcıda kullanıcıdan metin alır; dönüş her zaman string veya iptalde null'dur. Sayıya çevirmek için Number() veya parseInt() gerekir.

let ad = prompt("Adınız?");
console.log(ad);

const yas = 20;
// yas = 21;  // Hata: Assignment to constant variable

var eski = 1;  // Hâlâ çalışır ama önerilmez
Dikkatprompt Node.js ortamında yoktur; yalnızca tarayıcı API'sidir.

Değişken ve fonksiyon adları harf, _, $ ile başlayabilir; rakamla başlayamaz. Rezerve kelimeler (if, class, return) kullanılamaz.

JavaScript topluluğunda çok kelimeli isimlerde camelCase standarttır: ilk kelime küçük, sonrakiler büyük harfle başlar — örn. ogrenciSayisi, getUserName.

String İşlemleri: length, slice, birleştirme

String'ler karakter dizisidir. .length karakter sayısını verir (boşluklar dahil). .slice(baslangic, bitis) bitiş indeksini dahil etmez; negatif indeks sondan sayar.

let metin = "JavaScript";
metin.length;           // 10
metin.slice(0, 4);      // "Java"
metin.slice(-6);        // "Script"
metin.toUpperCase();
metin.includes("Script"); // true

İki string + ile birleştirilir; template literal ile değişken gömülür:

let ad = "Ayşe";
let selam = "Merhaba " + ad;
let selam2 = `Merhaba ${ad}, hoş geldin!`;

Matematik Operatörleri ve Öncelik

Aritmetik: + - * / % (mod/kalan). ++ ve -- bir artırır/azaltır. Karşılaştırma: >, <, >=, <=. Eşitlik için == (tip dönüşümü yapar) ve === (tip + değer) kullanılır; sınavda === tercih edin.

let a = 10, b = 3;
a + b;   // 13
a % b;   // 1
a === "10";  // false
a == "10";   // true (tip dönüşümü!)
Operatör=====
5 === "5"falsetrue
null == undefinedfalsetrue
Sınavda sorulabilir=== ile == farkını örnekli açıklayın; tip dönüşümü tuzakları sık sorulur.

Fonksiyonlar: Tanım, Parametre ve return

Fonksiyonlar tekrar kullanılabilir kod bloklarıdır. Parametreler parantez içinde, return sonucu çağırana döndürür; return yoksa undefined döner.

function topla(a, b) {
  return a + b;
}
let sonuc = topla(3, 5);  // 8

// Ok fonksiyonu (ES6)
const carp = (x, y) => x * y;

Fonksiyon ifadesi ve ok fonksiyonu farklı this davranışına sahiptir; DOM modülünde tekrar ele alınacaktır.

İpucuParametre sayısı fazla verilirse fazlalar yok sayılır; az verilirse eksikler undefined olur.

Math.random ve Zar Simülasyonu

Math.random() 0 ile 1 arasında (1 hariç) ondalıklı sayı üretir. Tam sayı aralığı için Math.floor kullanılır:

// 1 ile 6 arası zar (dahil)
let zar = Math.floor(Math.random() * 6) + 1;

// 0 ile 9 arası
let rakam = Math.floor(Math.random() * 10);

Formül: Math.floor(Math.random() * (max - min + 1)) + min hem min hem max dahil tam sayı verir.

Math.random() → 0.0 .. 0.999... × 6 → 0 .. 5.999... floor → 0 .. 5 + 1 → 1 .. 6 (zar)
Sınavda sorulabilir1-6 zar kodunu satır satır açıklama sorusu olarak gelebilir.

Koşullar: if, else if, else

Program akışı koşullara göre dallanır. Koşul ifadesi truthy/falsy değerlere indirgenir: 0, "", null, undefined, NaN falsy kabul edilir.

let puan = 85;
if (puan >= 90) {
  console.log("AA");
} else if (puan >= 70) {
  console.log("Geçti");
} else {
  console.log("Kaldı");
}

Mantıksal operatörler: && (ve), || (veya), ! (değil).

Dikkatif (x = 5) atama yapar, karşılaştırma değil! Karşılaştırma === olmalı.

Diziler (Arrays) ve includes

Dizi köşeli parantezle oluşturulur; indeks 0'dan başlar. .length, .push(), .pop(), .includes(deger) sık kullanılır.

let renkler = ["kırmızı", "yeşil", "mavi"];
renkler[0];              // "kırmızı"
renkler.push("sarı");
renkler.includes("mavi"); // true

let sayilar = [1, 2, 3];
for (let i = 0; i < sayilar.length; i++) {
  console.log(sayilar[i]);
}
İpucuDrum Kit projesinde tuş listesi dizi olarak tutulup includes ile kontrol edilebilir.

while Döngüsü

while (koşul) koşul true olduğu sürece blok çalışır. Sonsuz döngüden kaçınmak için döngü içinde koşulu değiştiren bir adım olmalıdır.

let i = 0;
while (i < 5) {
  console.log(i);
  i++;  // i = i + 1

DOM ve Olaylar (Ders 2)

JavaScript'i HTML'e Ekleme — 3 Yol

Harici dosya en temiz yöntemdir; HTML'in sonunda </body> öncesine yazılır ki DOM yüklensin. Satır içi ve dahili yöntemler küçük örnekler içindir.

  1. Harici: <script src="app.js"></script>
  2. Dahili: <script> ... kod ... </script> head veya body içinde
  3. Satır içi: onclick="..." gibi HTML özniteliğinde (önerilmez)
<!-- En iyi uygulama -->
<body>
  <h1 id="baslik">Merhaba</h1>
  <script src="js/app.js"></script>
</body>
DikkatScript'i <head>'e koyarsanız DOM henüz oluşmamış olabilir; DOMContentLoaded dinleyin veya script'i alta alın.

DOM Ağacı (Document Object Model)

Tarayıcı HTML'i ağaç yapısına çevirir: document kök, altında html, head, body, elementler ve metin düğümleri. JavaScript bu ağaca erişip içerik ve stil değiştirir — sayfa yenilenmeden etkileşim sağlanır.

document └── html ├── head (meta, title, link) └── body ├── h1, p, div ... └── script

Her element bir node'dur; ebeveyn-çocuk ilişkisi vardır. parentNode, children, firstElementChild ile gezilir.

Sınavda sorulabilirDOM'un ne olduğu: HTML'in programatik temsili, API ile erişim.

Öğe Seçimi: querySelector ve querySelectorAll

CSS seçicileri ile aynı sözdizimi kullanılır. querySelector ilk eşleşeni, querySelectorAll NodeList döndürür.

document.querySelector("h1");
document.querySelector(".btn-primary");
document.querySelector("#liste");
document.querySelectorAll("li");  // tüm li öğeleri

// Eski yöntemler (hâlâ bilin)
document.getElementById("baslik");
document.getElementsByClassName("kart");

DOM Manipülasyonu: innerHTML, textContent, style

textContent yalnızca metin ekler (XSS daha güvenli). innerHTML HTML parse eder; kullanıcı girdisiyle dikkatli olun. Stil için element.style.ozellik veya classList tercih edilir.

let baslik = document.querySelector("h1");
baslik.textContent = "Yeni başlık";
baslik.style.color = "blue";
baslik.classList.add("vurgulu");

let kutu = document.querySelector("#icerik");
kutu.innerHTML = "<p>Paragraf eklendi</p>";
DikkatinnerHTML ile kullanıcı verisi basmak XSS saldırısına açıktır; backend'de sanitize gerekir.

addEventListener ve Zar Oyunu Mantığı

Olay dinleyici, kullanıcı eylemini (tıklama, klavye) fonksiyona bağlar. İkinci parametre callback, üçüncü opsiyonel { capture, once }.

let btn = document.querySelector(".roll");
btn.addEventListener("click", function () {
  let r = Math.floor(Math.random() * 6) + 1;
  document.querySelector(".dice-img").setAttribute("src", "dice" + r + ".png");
});

Drum Kit örneğinde her tuşa click ve keydown bağlanır; ses dosyası new Audio(url) ile çalınır.

İpucuaddEventListener aynı olaya birden fazla handler ekleyebilir; onclick= tek handler'ı ezer.

switch Yapısı ve this Anahtar Kelimesi

switch bir değeri çoklu case ile karşılaştırır; break unutulursa fall-through olur. Drum Kit'te tuş harfine göre ses seçimi yapılır.

switch (tuş) {
  case "w":
    sesCal("tom-1");
    break;
  case "a":
    sesCal("kick");
    break;
  default:
    console.log("Tanınmayan tuş");
}

this, olay dinleyicisinde genelde olayı tetikleyen DOM öğesini gösterir (klasik function ile). Ok fonksiyonunda this lexical kapsamdadır — Drum Kit'te this.classList.add("pressed") tıklanan butona class ekler.

document.querySelectorAll(".drum").forEach(function (btn) {
  btn.addEventListener("click", function () {
    this.classList.add("pressed");
    let key = this.textContent;
  });
});

JavaScript Nesneleri (Objects)

Nesne süslü parantezle tanımlanır; özellikler anahtar-değer çiftidir. Nokta veya köşeli parantez ile erişilir.

let kullanici = {
  ad: "Mehmet",
  yas: 22,
  selamla: function () {
    return "Merhaba " + this.ad;
  }
};
kullanici.ad;
kullanici["yas"];

Dizi aslında özel bir nesnedir; fonksiyon da nesne sayılır. JSON veri alışverişinde nesne gösterimini kullanır.

Sınavda sorulabilirNesne ile dizi farkı: dizide indeks 0,1,2...; nesnede isimli anahtarlar.

Klavye Olayları: keypress, keydown, keyup

keydown tuşa basıldığında, keyup bırakıldığında tetiklenir. event.key hangi tuş olduğunu verir (ör. "w", "Enter").

document.addEventListener("keydown", function (e) {
  console.log(e.key);
  playSound(e.key);
});

Drum Kit: hem tıklama hem klavye aynı playSound fonksiyonunu çağırarak kod tekrarını azaltır.

Express Middleware ve EJS (Ders 5)

Express Middleware Zinciri

Express'te gelen her istek bir middleware zincirinden geçer. Middleware, (req, res, next) imzalı fonksiyondur; iş bitince next() çağrılmazsa istek asılı kalır.

İstek → middleware 1 → middleware 2 → route handler → Yanıt (log) (body parse) (GET /)
const express = require("express");
const app = express();

app.use((req, res, next) => {
  console.log(req.method, req.url);
  next();
});

app.use(express.static("public"));

app.get("/", (req, res) => {
  res.send("Ana sayfa");
});

express.static de bir middleware'dir; public klasöründeki CSS, resim dosyalarını doğrudan sunar.

Sınavda sorulabilirMiddleware sırasının önemi: body-parser route'tan önce olmalı.

body-parser ve Form Verisi

HTML formları application/x-www-form-urlencoded gönderir. Express 4.16+ için gömülü:

app.use(express.urlencoded({ extended: true }));
app.use(express.json());  // JSON API için

app.post("/kayit", (req, res) => {
  console.log(req.body);  // { ad: "...", email: "..." }
  res.redirect("/");
});

Eski ders notlarında ayrı body-parser paketi gösterilir; mantık aynıdır — gövde ayrıştırılır, req.body dolar.

Dikkatextended: true qs kütüphanesi ile karmaşık nesneleri parse eder; basit formlarda false da kullanılabilir.

EJS Temel Sözdizimi

EJS (Embedded JavaScript), HTML içine sunucu verisi gömmenizi sağlar. Express'te view engine olarak ayarlanır.

app.set("view engine", "ejs");

// views/index.ejs
<h1><%= baslik %></h1>
<p>Bugün: <%= new Date().toLocaleDateString("tr") %></p>
EtiketAnlam
<%= %>Değeri HTML'e escape ederek yaz
<% %>Kontrol akışı (if, for), çıktı yok
<%- %>Escape etmeden ham HTML

EJS Gelişmiş: include ve partial

Tekrarlayan header/footer parçaları ayrı dosyada tutulur:

<%- include("partials/header") %>
<main>
  <% if (kullanici) { %>
    <p>Hoş geldin, <%= kullanici.ad %></p>
  <% } else { %>
    <p>Lütfen giriş yapın.</p>
  <% } %>
</main>
<%- include("partials/footer") %>

include yolu views klasörüne göredir. Her sayfa aynı iskeleti paylaşır — bakım kolaylaşır.

EJS'e Veri Aktarımı: res.render ve locals

Route handler res.render("sablon", veriNesnesi) ile şablonu doldurur. İkinci argümandaki anahtarlar şablonda değişken olur.

const urunler = [
  { ad: "Kitap", fiyat: 50 },
  { ad: "Kalem", fiyat: 10 }
];

app.get("/urunler", (req, res) => {
  res.render("urunler", {
    baslik: "Ürün Listesi",
    urunler: urunler
  });
});

// urunler.ejs
<% urunler.forEach(function(u) { %>
  <li><%= u.ad %> - <%= u.fiyat %> TL</li>
<% }); %>
İpucuapp.locals tüm şablonlara ortak değişken verir (site adı gibi).

Veritabanları (Ders 7)

Veri Kalıcılığı (Data Persistence)

Değişkenler ve diziler program kapandığında kaybolur. Kalıcı veri dosya, veritabanı veya bulut depolamada tutulur. Web uygulamalarında kullanıcı kayıtları, siparişler, oturum bilgisi veritabanında saklanır.

  • Geçici: RAM, oturum (session store hariç kalıcı backend)
  • Kalıcı: PostgreSQL, dosya sistemi

Node.js + Express + PostgreSQL üçlüsü dersin backend omurgasıdır: istek → route → SQL sorgusu → sonuç → EJS veya JSON yanıt.

Sınavda sorulabilirNeden sunucu tarafı depolama? Çok kullanıcı, güvenlik, tutarlılık.

SQL vs NoSQL

ÖzellikSQL (PostgreSQL)NoSQL (MongoDB vb.)
YapıTablolar, sabit şemaDoküman, esnek şema
İlişkiPK, FK, JOIN güçlüGömülü veya uygulama tarafı
DilSQL sorgularıAPI / sorgu nesnesi
ÖrnekBanka, e-ticaret siparişLog, sosyal akış

Dersinizde PostgreSQL (ilişkisel) odaklıdır. Tablo satır-sütun mantığıyla Excel'e benzer ama çok kullanıcılı ve eşzamanlı erişime uygundur.

SQL CRUD: CREATE, INSERT, SELECT, WHERE

CREATE TABLE ogrenci (
  id SERIAL PRIMARY KEY,
  ad VARCHAR(100) NOT NULL,
  bolum_id INTEGER REFERENCES bolum(id)
);

INSERT INTO ogrenci (ad, bolum_id) VALUES ('Ali', 1);

SELECT * FROM ogrenci WHERE bolum_id = 1;

UPDATE ogrenci SET ad = 'Ali Veli' WHERE id = 1;
DELETE FROM ogrenci WHERE id = 1;

PRIMARY KEY (PK): Satırı benzersiz tanımlar. FOREIGN KEY (FK): Başka tablodaki PK'ya referans; bütünlük sağlar.

İpucuSELECT * öğrenmede iyidir; üretimde yalnızca gerekli sütunları seçin.

INNER JOIN ile Tablo Birleştirme

İlişkili veriyi tek sorguda çekmek için tablolar birleştirilir. INNER JOIN yalnızca her iki tabloda eşleşen satırları döndürür.

SELECT ogrenci.ad, bolum.bolum_adi
FROM ogrenci
INNER JOIN bolum ON ogrenci.bolum_id = bolum.id
WHERE bolum.id = 2;
ogrenci tablosu bolum tablosu id | ad | bolum_id id | bolum_adi 1 | Ali | 1 ←→ 1 | Bilgisayar
Sınavda sorulabilirJOIN'li sorgu yazma veya FK mantığını açıklama.

PostgreSQL

PostgreSQL Kurulum ve pgAdmin

PostgreSQL açık kaynak ilişkisel veritabanıdır. Windows'ta resmi installer ile kurulur; servis arka planda çalışır. pgAdmin grafik arayüz: veritabanı oluşturma, tablo tasarımı, sorgu çalıştırma.

  1. PostgreSQL indir ve kur (port varsayılan 5432).
  2. pgAdmin'de sunucuya bağlan (postgres kullanıcısı + şifre).
  3. Yeni Database → tablolar → Query Tool ile SQL.

Node projesinde bağlantı bilgileri .env dosyasında tutulur; şifre repoya yazılmaz.

Node.js pg Paketi ve dotenv

// npm install pg dotenv
require("dotenv").config();
const { Client } = require("pg");

const client = new Client({
  user: process.env.DB_USER,
  host: process.env.DB_HOST,
  database: process.env.DB_NAME,
  password: process.env.DB_PASSWORD,
  port: process.env.DB_PORT,
});

async function listele() {
  await client.connect();
  const sonuc = await client.query("SELECT * FROM sehirler");
  console.log(sonuc.rows);
  await client.end();
}

process.env ortam değişkenlerini okur; dotenv .env dosyasını yükler. Her istekte connect/end pahalıdır — havuz (pool) üretimde kullanılır.

Dikkat.env dosyasını .gitignore'a ekleyin.

CSV İçe Aktarma

Toplu veri CSV ile aktarılır: pgAdmin Import/Export veya Node'da COPY / satır satır INSERT. Başlık satırı sütun adlarıyla eşleşmeli.

-- pgAdmin veya psql
COPY ulkeler FROM 'C:/data/ulkeler.csv'
DELIMITER ','
CSV HEADER;

Node tarafında fs + csv-parse ile okuyup parametreli INSERT döngüsü de kurulabilir — SQL injection'a karşı parametreli sorgu şart.

Sınavda sorulabilirClient yaşam döngüsü: connect → query → end ve .env kullanımı.

Kimlik Doğrulama ve Şifre Güvenliği

Kimlik Doğrulama Neden Gerekli?

Authentication (AuthN), kullanıcının iddia ettiği kişi olduğunu doğrular. Authorization (AuthZ) ise neye erişebileceğini belirler. Kayıt olan herkesin admin paneline girmesi güvenlik felaketidir.

  • Kişisel veri (notlar, profil) korunur.
  • İş kuralları (sadece kendi siparişlerim) uygulanır.
  • Yasal uyumluluk (KVKK) için hesap sahipliği kanıtlanır.

Ders akışı: düz metin şifre → hash (bcrypt) → oturum (session/cookie) → Passport stratejileri.

Güvenlik Seviyeleri

SeviyeYöntemDeğerlendirme
DüşükŞifre veritabanında düz metinAsla kullanılmamalı
OrtaMD5/SHA1 hash (tuzsuz)Kırılabilir, eski
Yüksekbcrypt / scrypt + saltDers standardı
İletişimHTTPS (TLS)Ağda dinlemeyi önler

Şifre doğrulama asla "hash'i çöz" değil, girilen şifreyi hash'leyip veritabanındaki hash ile karşılaştırmaktır.

Sınavda sorulabilirAuthN vs AuthZ tanımı ve güvenlik seviyesi tablosu.

Şifreleme vs Hash ve bcrypt

Şifreleme (encryption): Anahtarla çözülebilir (AES). Hash: Tek yönlü; aynı girdi aynı çıktı (tuz ile değişir). Parolalar hash'lenir, şifrelenmez.

const bcrypt = require("bcrypt");
const saltRounds = 10;

// Kayıt
const hash = await bcrypt.hash(sifre, saltRounds);
// DB'ye hash kaydet

// Giriş
const eslesme = await bcrypt.compare(girilenSifre, dbHash);
if (eslesme) { /* oturum aç */ }

Hash tablosu (rainbow table) saldırısına karşı salt her kullanıcıya özgü rastgele veridir; bcrypt bunu gömülü yönetir.

DikkatHash'lenmiş şifreyi geri alamazsınız; "şifremi unuttum" akışı sıfırlama linki gerektirir.

Yaygın Saldırı Türleri

Çerezler, Oturum, Passport ve dotenv

HTTP Çerezleri (Cookies)

Tarayıcı, sunucunun gönderdiği küçük anahtar-değer çiftlerini saklar ve sonraki isteklerde Cookie başlığıyla geri gönderir. httpOnly JavaScript'in okumasını engeller (XSS koruması). secure yalnızca HTTPS'te gönderilir.

res.cookie("dil", "tr", { maxAge: 900000, httpOnly: true });

// Okuma
console.log(req.cookies.dil);  // cookie-parser gerekir
İpucuHassas veriyi çerezde saklamayın; oturum kimliği (session id) yeterlidir.

Oturum Yönetimi (express-session)

Session sunucu tarafında kullanıcı durumunu tutar; istemciye yalnızca session ID çerezi gider. Giriş sonrası req.session.userId gibi alanlar set edilir.

const session = require("express-session");

app.use(session({
  secret: process.env.SESSION_SECRET,
  resave: false,
  saveUninitialized: false,
  cookie: { maxAge: 1000 * 60 * 60 }  // 1 saat
}));

app.post("/login", (req, res) => {
  // doğrulama başarılı
  req.session.userId = kullanici.id;
  res.redirect("/dashboard");
});

Çıkış: req.session.destroy(). Oturum verisi varsayılan bellekte tutulur; üretimde Redis/PostgreSQL store kullanılır.

Passport.js: serialize, deserialize, req.user

Passport kimlik doğrulama middleware'idir. Yerel strateji (kullanıcı adı/şifre) veya OAuth (Google) eklenebilir.

passport.use(new LocalStrategy(async (username, password, done) => {
  const user = await findUser(username);
  if (!user || !(await bcrypt.compare(password, user.hash)))
    return done(null, false);
  return done(null, user);
}));

passport.serializeUser((user, done) => {
  done(null, user.id);  // oturumda yalnızca id
});

passport.deserializeUser(async (id, done) => {
  const user = await findUserById(id);
  done(null, user);  // req.user dolar
});

app.post("/login", passport.authenticate("local", {
  successRedirect: "/dashboard",
  failureRedirect: "/login"
}));

req.user deserialize sonrası her istekte kullanılabilir. req.isAuthenticated() giriş kontrolü için kullanılır.

Sınavda sorulabilirserialize vs deserialize: hangisi oturuma ne yazar, hangisi DB'den kullanıcı yükler.

API ve REST

API (Application Programming Interface) Giriş

API, yazılım bileşenlerinin konuşma sözleşmesidir. Web API'leri HTTP üzerinden JSON/XML döner. Ön yüz (React) ile backend (Express) ayrıldığında frontend yalnızca API çağırır.

  • Public API: Hava durumu, harita servisleri
  • Kendi API'niz: Mobil uygulama + aynı sunucu

Endpoint = URL + HTTP metodu + isteğe bağlı gövde/parametreler.

REST API ve HTTP Metodları

REST, kaynakları URL ile tanımlar ve standart HTTP fiilleri kullanır. Stateless: her istek gerekli bilgiyi taşır (oturum token hariç sunucu hafızası yok).

MetodİşlemÖrnek
GETOkumaGET /api/urunler
POSTOluşturmaPOST /api/urunler
PUTGüncelleme (tam)PUT /api/urunler/5
DELETESilmeDELETE /api/urunler/5

Query params vs Path params

// Path param: /api/urunler/42  → req.params.id
app.get("/api/urunler/:id", (req, res) => {
  res.json({ id: req.params.id });
});

// Query: /api/urunler?kategori=kitap&limit=10
app.get("/api/urunler", (req, res) => {
  const { kategori, limit } = req.query;
});
Sınavda sorulabilirRESTful route tasarlama ve GET/POST farkı (GET gövde taşımaz, önbelleklenir).

JSON: stringify ve parse

JSON metin tabanlı veri formatıdır; JavaScript nesnelerine çok benzer. API'lerde standarttır.

const nesne = { ad: "Zeynep", notlar: [85, 90] };
const metin = JSON.stringify(nesne);
// '{"ad":"Zeynep","notlar":[85,90]}'

const geri = JSON.parse(metin);
console.log(geri.ad);

// Express JSON yanıt
res.json({ basarili: true, veri: geri });

express.json() middleware gelen JSON gövdesini req.body'ye parse eder.

DikkatJSON.parse hatalı metinde exception fırlatır; try/catch kullanın.

Axios ile İstemci Tarafı İstek

Axios tarayıcı ve Node'da HTTP isteği yapar; Promise tabanlıdır, JSON otomatik işlenir.

// npm install axios  veya CDN
const axios = require("axios");

async function urunleriGetir() {
  const yanit = await axios.get("http://localhost:3000/api/urunler");
  console.log(yanit.data);

axios.post("/api/kayit", { ad: "Can", email: "can@mail.com" })
  .then(res => console.log(res.status))
