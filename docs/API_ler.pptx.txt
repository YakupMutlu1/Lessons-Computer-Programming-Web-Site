--- Slayt 6 ---
API Mimarileri
REST API Nedir?REST = Representational State Transfer
Temel Prensipler:
HTTP Protokolü kullanılır
Kaynaklar (Resources) URL'lerle temsil edilir
HTTP Metodları ile işlemler yapılır:
GET → Veri al
POST → Veri oluştur
PUT → Veriyi tamamen güncelle
PATCH → Veriyi kısmen güncelle
DELETE → Veri sil
GET    /api/users           → Tüm kullanıcıları getir
GET    /api/users/123       → ID'si 123 olan kullanıcıyı getir
POST   /api/users           → Yeni kullanıcı oluştur
PUT    /api/users/123       → 123 numaralı kullanıcıyı güncelle
DELETE /api/users/123       → 123 numaralı kullanıcıyı sil
Neden REST Popüler?
Basit ve anlaşılır
HTTP zaten bildiğimiz bir protokol
Her dil ve platformda kullanılabilir
Ölçeklenebilir

API İsteklerini Yapılandırma (Özel API vs Genel API)
Özel API (Private API):
Kendi ön yüzünüz ile arka yüzünüz arasındaki iletişim
Belgelendirilmemiş
Sadece sizin uygulamanıza hizmet eder


Genel API (Public API):
Başka bir sunucu ile iletişim kurma
Belgelendirilmiş
Herkesin kullanımına açık
API Uç Noktaları (Endpoints)
Endpoint Nedir?
API sağlayıcının sunucusunda farklı bir rota
Her endpoint farklı bir amaç için
API dokümantasyonunda listelenir

JSON(JAVASCRIPT OBJECT NOTATION) - JavaScript Nesne Gösterimi
JSON Nedir?
Tanım:
Verileri internet üzerinden göndermek için okunabilir ve verimli bir format
JavaScript nesneleri gibi yapılandırılmıştır
"Düz paket" (flat pack) formatı
JavaScript Nesnesi vs JSON Karşılaştırması:
javascript
{
  kapı: 2,
  çekmece: 3,
  renk: "beyaz"
}
JSON
{
 " kapı " : 2,
 " çekmece " : 3,
 " renk " : "beyaz"
}
