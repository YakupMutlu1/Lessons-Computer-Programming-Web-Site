--- Slayt 6 ---
Belge Nesne Modeli (DOM)
DOM Nedir?
Statik web siteleri etkileşimli değil
Kullanıcı tıkladığında değişemiyor
HTML/CSS'yi canlıda değiştiremeyiz
DOM (Document Object Model)
Tarayıcı HTML'yi nesnelere dönüştürür
Her element seçilebilir ve manipüle edilebilir
JavaScript ile dinamik değişiklikler yapılabilir
document
└── html
    ├── head
    │   └── title ("Örnek")
    └── body
        ├── h1 ("Merhaba")
        └── button ("Tıkla")

İlişkiler:
Ebeveyn/Çocuk: html → head/body
Kardeşler: head ve body kardeştir
Soy: h1, body'nin çocuğu, html'nin torunudur

--- Slayt 8 ---
DOM'da Gezinme
Metodları Çağırma (Methods):
// Checkbox'ı seç ve tıkla
var checkbox = document.querySelector("input");
checkbox.click();  
// Tıklama metodunu çağır
// Button'a olay dinleyici ekle
var button = document.querySelector("button");
button.addEventListener("click", function() {
  alert("Tıklandı!");
});
Özellik vs Metod:
Özellik: .innerHTML, .style, .className (değer alır/atanır)
Metod: .click(), .addEventListener() (parantezle çağrılır)
Özet:
// Button nesnesi
var button = document.querySelector("button");
// Özellikler
button.innerHTML    // Metin içeriği
button.style        // Stil özellikleri
button.disabled     // Devre dışı mı?
// Metodlar
button.click()      // Tıklama simülasyonu
button.focus()      // Odaklanma
Önemli Çıkarımlar:
DOM, HTML'in nesne temsili
Nesnelerin özellikleri ve metodları vardır
Özellikler değerleri tanımlar (.innerHTML, .style)
Metodlar nesnenin yapabilecekleridir (.click(), .addEventListener())
Nokta notasyonu ile erişilir: object.property veya object.method()

Buton tıklamalarıyla aynı mantığı kullan
Buton Tıklamalarından Farkı:
Bağlanacak belirli bir HTML elementi yok
Tüm belgeyi/pencerreyi dinle
Event türü: "keypress "
document.addEventListener("keypress", function() {
  alert("Tuşa basıldı!");
});
Event Türleri:
"keypress" - Karakter tuşuna basıldı (w, a, s...)
"keydown" - Herhangi bir tuşa basıldı (Shift, Ctrl dahil)
"keyup" - Tuş bırakıldı
// Tüm belgeyi hedefle
document.addEventListener("keypress", function() { });

// Veya belirli elementi hedefle (odaklanmışsa)
inputElement.addEventListener("keypress", function() { });
Hangi Tuşa Basıldığını Belirleme
Altı Başlık: Event Objesi Parametresi
Problem: Tuşa basıldığını biliyoruz ama hangisi?


Kosolda bu kodu yazalım:
document.addEventListener("keypress", function(event) {
  // 'event' tuş basımı hakkında bilgi içerir
  console.log(event);
});

--- Slayt 28 ---
İlk Event Listener Ekleme
Event Objesi Özellikleri:
event.key - Karakter (w, a, s, d, j, k, l)
event.keyCode - Tuşun sayısal kodu
event.code - Fiziksel tuş konum adı
event.shiftKey - Shift basılı mıydı?
Tuşu Alma:
document.addEventListener("keypress", function(event) {
  console.log("Basılan tuş: " + event.key);
  console.log("Tuş kodu: " + event.keyCode);
});
Fonksiyonla Yeniden Yapılandırma
Yeniden Kullanılabilir Ses Fonksiyonu Oluşturma
Problem: Yinelenen switch ifadesi mantığı
Buton tıklaması: buttonInnerHTML üzerinde switch
Klavye basımı: event.key üzerinde switch
Çözüm: Ortak mantığı bir fonksiyona çıkartacağız
// Tuşa göre ses çalma fonksiyonu
function sesiVerin(key) {
  switch(key) {
    case "w":
      var tom1 = new Audio("sounds/tom-1.mp3");
      tom1.play();
      break;
    case "a":
      var tom2 = new Audio("sounds/tom-2.mp3");
      tom2.play();
      break;
    // ... diğer case'ler
  }
}

--- Slayt 29 ---
İlk Event Listener Ekleme
Şu an iki farklı fonksiyonu Kullananacağız:
// Buton tıklamaları için
button.addEventListener("click", function() {
  sesVerin(this.innerHTML);
});

// Klavye basımları için
document.addEventListener("keypress", function(event) {
  sesVerin(event.key);
});
Nasıl Çalışır:
Buton Tıklaması: this.innerHTML buton metnini alır (w, a, s...)
Tuş Basımı: event.key klavye tuşu karakterini alır
Her ikisi de karakterle sesVerin(key) çağırır
Switch ifadesi o karakter için doğru sesi çalar

Önemli Çıkarımlar:
document.addEventListener("keypress", ...) klavye girişini dinler
Event objesi parametresi tuş bilgisini içerir
event.key basılan karakteri verir
Yeniden kullanılabilir fonksiyonlar kod tekrarını önler
Aynı mantık hem buton tıklamalarını hem de klavye basımlarını işleyebilir
Farklı tuşlarla test et büyük harf, özel karakterler dahil
