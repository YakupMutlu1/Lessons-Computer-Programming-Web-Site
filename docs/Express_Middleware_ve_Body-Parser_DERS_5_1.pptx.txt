EJS ile Veri Aktarımı
locals ile Güvenli Veri Kontrolü
locals Nedir?
res.render ile gönderilen TÜM değişkenleri içeren özel nesne
Her EJS dosyasında otomatik olarak bulunur
Değişkenlerin varlığını güvenle kontrol etmemizi sağlar
Problemi Çözelim:
<!-- index.ejs - GÜVENLİ versiyon -->
<ul>
  <% if (locals.meyveler) { %>  <!-- ⭐ ÖNCE VAR MI KONTROL ET -->
    <% meyveler.forEach(function(meyve) { %>
      <li><%= meyve %></li>
    <% }); %>
  <% } else { %>
    <p>Henüz meyve eklenmemiş.</p>
  <% } %>
</ul>

--- Slayt 22 ---
EJS ile Veri Aktarımı
Sunucuda POST İsteğini Yakalama:
// index.js
import bodyParser from 'body-parser';
app.use(bodyParser.urlencoded({ extended: true }));

app.post("/submit", (req, res) => {
  const ad = req.body.fName;      // "fName" input'undan gelen
  const soyad = req.body.lName;    // "lName" input'undan gelen
  console.log(ad, soyad);
  // İşlem yap, sonra tekrar render et
  res.render("index");
});
Önemli Noktalar:
action="/submit" → POST isteğinin gideceği rota
method="POST" → İstek türü
name="fName" → req.body.fName ile erişilecek anahtar
Body-parser olmazsa req.body = undefined

  const ad = req.body.fName;
